# Research

Rule 0: blunt. Report what the evidence says, including when it kills the idea.
1. **Frame:** the question, and the decision it changes. Without a decision, do not research.
2. **Sources,** in priority order:
   1. official / primary (platform docs, open-source code, filings, Carta-style datasets)
   2. authoritative technical docs
   3. quality research
   4. reputable secondary
   5. community (experience only)
   Run independent searches in parallel. Stop when new sources stop changing the answer.
3. **Label each claim:** FACT · EVIDENCE · INFERENCE · ASSUMPTION · HYPOTHESIS · PROJECTION · UNKNOWN. Mark third-party numbers `(vendor)`.
4. **Keep only facts that change the decision.** Surface contradictions. Never fill a gap; write UNKNOWN.
5. **Output** (one page max):
   - `Answer:` one line
   - `Decision impact:` what to do
   - `Facts:` each with URL + date
   - `Unknowns:`
   - `Confidence:` low / medium / high
6. **Save** reusable findings in the right home (`WOLF/GROW.md`, `WOLF/STACK.md`, or the project doc) with the date. Re-research anything older than 90 days before relying on it.

**Market questions:** size bottom-up (users × price × frequency), never top-down only. Name the real alternatives, including "do nothing" and spreadsheets.
**Monthly AEO check:** ask the 10 buyer questions from `GROWTH.md` in ChatGPT, Claude and Perplexity. Log who is cited and why.
