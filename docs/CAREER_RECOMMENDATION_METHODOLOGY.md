# Career and education recommendation methodology (Stage 2–3; not yet built)

- Neither India nor abroad is assumed better. Pathways considered only when relevant: (A) study and work in India, (B) India then international specialisation, (C) abroad now, (D) work first, (E) skills/research/entrepreneurship routes.
- Profile stays in the browser (D-004). Under-18 users get no tracking.
- Inputs used only from official sources: UGC/AICTE recognition, NIRF, AISHE, official fee pages, official scholarship portals (NSP), official immigration/work-authorisation pages, PLFS and other official labour data.
- Never fabricated: placement rates, salaries, admission odds, employment probabilities. A salary appears only with geography, currency, year, experience level and source.
- Every recommendation shows: pathway, evidence, alternatives, cost range (not false precision), assumptions, risks, missing information, an action plan, confidence and limits. Nothing is guaranteed.
- Opportunities are labelled "open" only after a dated status check.
