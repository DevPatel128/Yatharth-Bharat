# AI research policy

- AI is never the authority. Code owns calculations, validation, permissions and publication decisions. A model can only **fail** a record (G6/G8); it can never publish, edit or invent one.
- One gateway: `src/lib/ai.ts` `askAI(task, …)`. Business code names a task, never a model. Registry today: adversarial review and Hindi back-translation → `claude-sonnet-5-5`; answers (Stage 1f) → `claude-haiku-5-5`.
- Retrieved documents are untrusted data: passed inside `<document>` tags with an explicit instruction that nothing inside is an instruction. Verdicts are parsed strictly; anything unparseable counts as a failed review.
- Keys are server-side only (pipeline env, Worker secrets). Never in the browser bundle.
- **Ask (`/ask`, `POST /api/ask`, built 2026-10-11):** retrieval only over this site's verified records (no web search, no stored PDFs yet), top 6 records passed as numbered `<document>` blocks. Code accepts an answer only if every citation number points at a supplied record, every number in the answer appears in a cited record (or the question), and the text passes the G7 lint (`guardAnswer` in `src/lib/ask.ts`); otherwise only the matching records are shown. Per-IP rate limit (5 per minute, hashed IP, Workers Rate Limiting binding) and a global daily cap (`ASK_DAILY_CAP`, default 300 model calls, KV counter) bound spend: at Haiku prices about US$0.0004 a call, so at most about US$4 a month. Answers are labelled "AI-generated summary of the cited sources" (IT Rules amendment, in force 20 Feb 2026). Without a Worker secret the page lists matching records and says written answers are off; it never fakes an answer. Not yet: Turnstile (add if abuse appears), Citations API quote re-checks against stored documents.
- Facts already in records are answered by deterministic queries, not a model.
- User questions are not stored beyond a hashed 24-hour cache and never used for training.
